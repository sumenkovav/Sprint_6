# Финальный проект: Автоматизация тестирования Яндекс.Самоката (Спринт 6)

## О проекте
Автоматизированное тестирование процесса оформления заказа самоката на сайте Яндекс.Самокат. Реализован полный флоу заказа через разные точки входа с проверкой финального статуса.

## Стек технологий
- **Язык:** Python 3.14
- **Фреймворк:** Pytest
- **Паттерн:** Page Object Model (POM)
- **Локаторы:** Selenium WebDriver (`By.XPATH`, `By.ID` и др.)
- **Отчётность:** Allure Report
- **Браузер:** Firefox (в режиме UI)

## Структура проекта

Sprint_6/
├── pages/                # Классы страниц (POM)
│   ├── base_page.py      # Базовый класс с общими методами
│   ├── main_page.py      # Методы для главной страницы
│   └── order_page.py     # Методы для страницы заказа
├── locators/             # Локаторы элементов
│   ├── main_page_locators.py
│   └── order_page_locators.py
